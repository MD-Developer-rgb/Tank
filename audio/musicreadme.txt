------------------------------------------------------------
THE LAST FIVE NIGHTS - AUDIO README
Created by MD Developer
------------------------------------------------------------
Paste all your audio files DIRECTLY into this "audio" folder.
Use the EXACT file names below (all in .mp3 format).
If a file is missing the game still works, it just stays silent for that sound.
Volume of Music and SFX can be changed in Settings.

[MUSIC AND AMBIENT]
NOTE: menu_music, chase_music and ending_music are optional - the game generates its own versions
when the files are missing. Your mp3 files replace them.

menu_music.mp3            LOOP   Dark, slow, eerie music for the home screen
ending_music.mp3                 Short theme played during the escape cut-scenes
ambient_forest_night.mp3  LOOP   Quiet forest night: crickets, distant owl, soft wind
rain_loop.mp3             LOOP   Steady rain on leaves and ground
wind_loop.mp3             LOOP   Wind through trees
chase_music.mp3           LOOP   Tense, fast music while the Hollow chases you
win_sting.mp3                    Short relief/victory sound for the ending
caught_sting.mp3                 Short loud jump-scare sound when caught
thunder.mp3                      Distant thunder (random lightning)

[THE HOLLOW]

Total: about 50 files. You do not need all of them.
------------------------------------------------------------
NOTE (v1.0): every sound EFFECT above is already built into the game and
generated in code, so the game has full sound with this folder empty.
The only files you really need to add are the MUSIC ones:
  menu_music.mp3  and  chase_music.mp3
Optional: ambient_forest_night.mp3, rain_loop.mp3, wind_loop.mp3 - if you add
them they replace the built-in ambience loops.
